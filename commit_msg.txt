Added Commander Brackets, set release notes and the rules judge; also fixed Deck Builder layout

Commander Brackets system implementation
- Deck Builder checks Commander decks against Wizards' brackets system: the lowest
  bracket the cards fit, Game Changers, mass land denial, extra turns and
  two-card combos (Commander Spellbook), with a per-deck target bracket and
  cards that break it marked in red
- Recommended tab leaves out cards that don't fit the target bracket and marks
  Game Changers
- Rules window: Commander Brackets page (every bracket, the terms, the
  current Game Changers list, history), bracket answers in "Ask a Rules
  Question", a guide and verified Q&As in the rules library
- Game Changer flag stored from Scryfall's card data (card database
  re-downloads once)

Rules
- Rules judge (judge.py): combat, timing, state and token questions worked
  out from the Comprehensive Rules
- Set release notes back to Ice Age and MTG Wiki mechanic/set pages
  (set_notes.py), searchable in the rules window
- The rules judge isn't perfect, and needs to be fine-tuned! Leave any rules
  interaction questions you guys have in a text file and submit it (I'll
  figure a system out for this in a few days) so I can train it. It's trained
  based on the official rules, card rules, and game rulings.

Fixes

- Deck Builder no longer widens when switching to Explore; card grids fill
  their width, the system now uses one card size everywhere, and the card panel gets more
  room than the deck list
- Main window fits the screen, with a scrolling details panel
